# Shared Terms

Use consistent terminology across backend, frontend, mobile, admin and QA.

Customer = end user placing a delivery order.
Store = merchant/business receiving and preparing an order.
Driver = delivery person executing an assigned order.
Admin = platform operator.

Order = delivery transaction.
Assignment = system relationship between an order and driver.
Collection = money collected from customer by driver.
Ledger = immutable-ish financial event history used for reconciliation.
