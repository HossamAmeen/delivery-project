# Admin Dashboard MVP Scope

## Simple MVP
1. Dashboard overview
2. Orders list
3. Order details
4. Stores list/details
5. Drivers list/details
6. Customers list/details
7. Basic search/filter
8. Basic operational status
9. Basic financial visibility

## Advanced later
- advanced analytics
- deep financial reconciliation
- configurable assignment rules
- advanced reporting
- audit explorer
- operational maps
- bulk operations

The MVP should not become an ERP. Advanced modules should be introduced
only when a concrete operational need exists.
