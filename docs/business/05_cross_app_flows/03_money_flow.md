# Cross-App Money Flow

1. Customer order total is calculated by backend.
2. Order stores a financial snapshot.
3. Driver sees amount expected from customer.
4. Driver collects the required amount when applicable.
5. Driver sees store-related amount/fee.
6. Delivery completion records the actual collection.
7. Ledger records are created.
8. Admin/store financial views use ledger/order records.

Any discrepancy must be explicit and auditable.
